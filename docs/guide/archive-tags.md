# 档案标签

档案标签用于为档案打标，支持层级结构（父标签 - 子标签），方便按主题快速筛选。

## 标签列表

进入【档案标签】页面：

![标签列表](/images/tags-list.png)

列表展示：

- 标签名称
- 父标签
- 备注

## 添加标签

点击右上角 **+ 添加标签** 按钮：

| 字段 | 说明 |
|------|------|
| 标签名称 | 必填 |
| 父标签 | 可选，选择已有标签作为上级 |
| 备注 | 可选 |

## 层级关系

- 不选择父标签时，标签为顶层标签；
- 选择父标签后，标签会显示在该父标签的下一级；
- 编辑标签时，系统会自动排除自身及其下级标签，避免循环关联。

## 批量删除

勾选标签行首的复选框，选择多个标签后，点击 **批量删除** 按钮可一次性删除。删除父标签时会同时删除其所有下级标签。

## 编辑与删除

- **编辑**：修改标签名称、父标签或备注；
- **删除**：删除单个标签，其下级标签会一并删除。

> 提示：在【档案管理】中登记或编辑档案时，可以在标签树中选择多个标签进行关联。
