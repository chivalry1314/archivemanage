# 安装与启动

## 下载安装包

1. 打开 GitHub 仓库的 [Releases](https://github.com/chivalry1314/archivemanage/releases) 页面；
2. 找到最新版本，根据你的操作系统下载对应的安装包：

| 操作系统 | 安装包类型 | 说明 |
|----------|------------|------|
| Windows | `.exe`（NSIS 安装包） | 双击运行安装向导 |
| macOS | `.dmg` | 打开后将应用拖入“应用程序”文件夹 |
| macOS (Apple Silicon) | `_aarch64.dmg` | 适用于 M1/M2/M3 系列 Mac |
| macOS (Intel) | `_x64.dmg` | 适用于 Intel 芯片 Mac |

3. 下载完成后，按常规方式安装即可。

## 首次启动（初始化向导）

安装完成后，从开始菜单、启动台或应用程序文件夹启动 **档案管理OS**。

首次启动时软件还没有数据库，会显示**初始化向导**，引导你选择数据库文件的存放位置。所有档案、任务和合同数据都会保存在这一个 SQLite 文件中。向导提供三个选项：

- **选择存放位置（新建数据库）**：在弹出的对话框中指定一个目录和文件名（如 `archivemanage.db`），软件会在该位置创建新的空数据库；
- **选择已有的数据库文件**：如果你之前备份过或从其他电脑迁移了 `.db` 文件，可以直接选择它来继续使用其中的数据；
- **使用默认位置**：在应用数据目录下创建数据库，适合不确定选哪里时使用。

选择建议：

- 建议选择便于备份的目录，例如 D 盘或文档目录；
- 请勿选择系统目录（如 Program Files），可能没有写入权限；
- 之后也可以在【设置】页面修改存放位置（见 [设置](settings.md#数据备份与存储位置)）。

确认后软件会自动完成初始化并重启，随后即可正常使用。

## 单实例运行

档案管理OS 限制同时只能运行一个程序实例。如果你已经打开了一个窗口，再次启动程序时，系统会自动将已有窗口置顶显示，而不会打开第二个窗口。这样可以避免多实例同时操作数据库导致数据不一致。

## 界面介绍

启动后进入主界面：

![主界面](/images/main-layout.png)

### 主要区域

1. **左侧导航栏**：快速切换各功能模块；
2. **顶部标题**：显示当前所在页面；
3. **内容区**：展示数据列表、统计卡片、表单等。

### 系统托盘

点击窗口右上角关闭按钮时，软件不会完全退出，而是最小化到系统托盘：

- 任务到期前会弹出桌面提醒；
- 档案借还逾期时也会收到提醒；
- 需要彻底退出时，右键点击托盘图标并选择退出。

## 更新版本

当有新版本发布时：

1. 下载对应平台的最新安装包；
2. 直接安装即可覆盖旧版本；
3. 数据库文件会自动保留，无需重新录入数据。

> 注意：如果修改过数据库路径，升级前请确认路径设置，避免误用空数据库。
