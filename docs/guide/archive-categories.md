# 档案分类

档案分类用于对档案进行归类管理，并作为档案编号的前缀来源。

## 分类列表

进入【档案分类】页面：

![分类列表](/images/categories-list.png)

列表展示：

- 分类名称
- 编号前缀
- 备注

## 添加分类

点击右上角 **+ 添加分类** 按钮：

| 字段 | 说明 |
|------|------|
| 分类名称 | 必填，如“业主档案” |
| 编号前缀 | 必填，大写字母，如 `YZ`、`SB`、`HT` |
| 备注 | 可选 |

保存后，新建档案时可在分类下拉框中选择该分类，档案编号会自动使用该前缀。

## 编辑与删除

- **编辑**：修改分类名称、编号前缀或备注；
- **删除**：删除分类后，该分类下的档案将失去分类关联，档案编号不再更新。

> 提示：编号前缀通常使用两位大写字母，便于快速识别档案类型。
