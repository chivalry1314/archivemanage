# 任务管理

任务管理用于创建和维护周期性任务。系统会根据任务的周期配置，自动生成需要执行的实例。

## 任务列表

进入【任务管理】页面，可看到所有已创建的任务：

![任务列表](/images/tasks-list.png)

列表展示：

- 任务名称与说明
- 周期类型（每月 / 每季度 / 每半年 / 每年）
- 每月执行日期
- 被指派人
- 提前提醒时间

## 新建任务

点击右上角 **+ 新建任务** 按钮，填写任务表单：

| 字段 | 说明 |
|------|------|
| 任务名称 | 必填，任务标题 |
| 任务说明 | 可选，补充描述 |
| 周期 | 必填，支持每月 / 每季度 / 每半年 / 每年 |
| 每月几号 | 必填，周期为“每月”时生效 |
| 开始日期 | 必填，任务生效的起始日期 |
| 结束日期 | 可选，任务停止生成的日期 |
| 提前提醒 | 任务到期前多少分钟提醒 |
| 声音提醒 | 是否在提醒时播放提示音 |
| 指派人员 | 可选，从【人员管理】中选择 |

填写完成后点击 **保存**。

> 提示：如果“指派人员”列表为空，请先到【人员管理】添加员工。

## 编辑与删除

- **编辑**：点击任务行右侧的 **编辑** 按钮，修改后保存；
- **删除**：点击 **删除** 按钮，确认后删除该任务及其所有历史实例。

## 查看任务实例

点击任务行右侧的 **实例** 按钮，弹出任务实例列表：

![任务实例](/images/task-instances.png)

实例列表显示根据周期生成的每一条待办记录，包括：

- 截止日期
- 当前状态（待办 / 已完成 / 逾期）

可在实例列表中直接标记完成或撤销完成。

## 任务详情

双击任务行可查看任务详情弹窗，展示任务的完整信息。
