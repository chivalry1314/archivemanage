# 设置

设置页面用于分页、数据库路径、AI 识别等系统配置以及手机搜索服务管理。

> 提示：任务数据导出在【任务管理】页面，档案导入导出在【档案管理】页面，合同导入导出在【合同管理】页面。

## 列表分页设置

设置各列表页面每页显示的条数，范围 **5~100**。修改后点击 **保存** 即可生效。

## 数据备份与存储位置

页面会显示当前数据库文件的完整路径。你可以：

- 直接复制该 `.db` 文件进行备份；
- 点击 **修改数据库路径** 更换数据库存放位置。

修改路径时可选是否迁移现有数据：

- **勾选“迁移现有数据”**：如果目标位置没有数据库，则将旧数据库复制到新位置；如果目标位置已有数据库，则直接打开已有数据库，不会覆盖；
- **不勾选**：在新位置创建空数据库。

修改成功后，软件会自动重启。

### 配置文件路径

配置文件（`config.json`）保存数据库路径、AI 配置等信息，首次启动时由初始化向导放置在数据库同一目录下。页面会显示当前配置文件的完整路径，点击 **修改配置文件路径** 可更换存放位置：

- **勾选“迁移现有配置”**：如果目标位置没有配置文件，则将现有配置复制到新位置；如果目标位置已有配置文件，则直接使用该文件，不会覆盖；
- **不勾选**：在新位置写入当前配置（目标位置已有文件时同样直接使用该文件）。

修改后即时生效，无需重启。

## 档案盒 AI 识别

在设置页可以开启档案盒 AI 识别功能：

![档案盒 AI 识别设置](/images/settings-ai.png)

1. 勾选 **启用档案盒 AI 识别**；
2. 填写 **API 地址**（硅基流动默认 `https://api.siliconflow.cn/v1`）；
3. 填写 **API Key**；
4. 点击 **获取模型**，从服务商拉取可用模型列表；
5. 在 **模型名** 下拉框中选择要使用的模型；
6. 点击 **保存 AI 配置**。

配置完成后，在【档案管理】登记档案时，填写档案名称后即可使用 **AI 识别** 按钮自动推荐档案盒。

> 注意：API Key 仅保存在本地 `config.json` 中，请妥善保管。

## 手机搜索服务

开启后，同一局域网下的手机可通过浏览器访问指定地址搜索档案。

![手机搜索服务](/images/mobile-server.png)

### 使用步骤

1. 设置端口号（默认 `8421`，范围 1024~65535）；
2. 点击 **开启服务**；
3. 确保手机和电脑连接同一 WiFi；
4. 用手机浏览器访问页面上显示的地址；
5. 需要停止时点击 **停止服务**。

> 注意：服务只在电脑运行时可用，首次开启可能需要放行 Windows 防火墙。
