# 设置

设置页面用于数据导出、导入、系统配置以及手机搜索服务管理。

## 任务数据导出

支持将任务相关数据导出为以下格式：

- **导出任务实例 (CSV)**：导出所有任务实例记录；
- **导出人员统计 (CSV)**：导出按人员汇总的任务完成情况；
- **导出 JSON**：导出任务数据的 JSON 文件，便于备份或二次开发。

点击对应按钮后，浏览器会自动下载文件。

![数据导出](/images/settings-export.png)

## 档案数据导出

- **导出档案台账 (CSV)**：导出所有档案的基本信息；
- **导出借还记录 (CSV)**：导出所有借还流水。

## 档案导入

支持从 Excel 文件导入档案台账：

1. 点击 **下载导入模板**，获取标准格式的 `.xlsx` 模板；
2. 按模板填写档案数据；
3. 点击 **选择 Excel 文件导入**，选择填写好的文件；
4. 系统会提示导入结果。

### Excel 格式要求

- 第一个 Sheet 为数据表；
- 第一行为表头，需包含：`具体材料`、`档案盒名称`、`标签`；
- 第二行起为数据；
- 未指定材料的标签也会自动创建；
- 未指定分类的档案归入“未知分类”，保管人默认为“未知保管人”。

## 列表分页设置

设置各列表页面每页显示的条数，范围 **5~100**。修改后点击 **保存** 即可生效。

## 数据备份与存储位置

页面会显示当前数据库文件的完整路径。你可以：

- 直接复制该 `.db` 文件进行备份；
- 点击 **修改数据库路径** 更换数据库存放位置。

修改路径时可选是否迁移现有数据：

- **勾选“迁移现有数据”**：将旧数据库复制到新位置；
- **不勾选**：在新位置创建空数据库。

修改成功后，软件会自动重启。

## 手机搜索服务

开启后，同一局域网下的手机可通过浏览器访问指定地址搜索档案。

![手机搜索服务](/images/mobile-server.png)

### 使用步骤

1. 设置端口号（默认 `8421`，范围 1024~65535）；
2. 点击 **开启服务**；
3. 确保手机和电脑连接同一 WiFi；
4. 用手机浏览器访问页面上显示的地址；
5. 需要停止时点击 **停止服务**。

> 注意：服务只在电脑运行时可用，首次开启可能需要放行 Windows 防火墙。
