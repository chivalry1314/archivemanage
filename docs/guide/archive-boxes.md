# 档案盒维护

档案盒是档案管理中用于归类存放纸质或电子档案的容器。在登记档案前，建议先在【档案盒维护】中创建常用档案盒，登记档案时即可直接选择，避免重复输入。

## 进入档案盒维护

点击左侧菜单 **档案盒维护**，进入档案盒管理页面。

![档案盒维护](/images/archive-boxes-list.png)

## 档案盒字段

| 字段 | 说明 |
|------|------|
| 档案盒名称 | 必填，如“1号楼业主盒”、“合同档案盒” |
| 存放位置 | 可选，如“档案室-A柜-3层”。该位置会作为档案的默认存放位置自动带出 |
| 备注 | 可选，补充说明 |

## 增删改查

- **添加**：点击右上角 **+ 添加档案盒**，填写信息后保存；
- **编辑**：点击档案盒行尾的 **编辑** 按钮；
- **删除**：点击 **删除** 按钮。如果档案盒下仍有档案，系统会提示无法删除，需要先将档案移到其他档案盒；
- **搜索**：顶部搜索框支持按名称、存放位置、备注模糊搜索；
- **分页**：底部可切换页码和每页条数。

## 与档案登记的联动

登记或编辑档案时：

- “档案盒”字段必须从已有的档案盒中选择，不能手动输入；
- 选择档案盒后，系统会自动带出该档案盒的存放位置；
- 如果档案盒未设置存放位置，则默认使用档案盒名称作为存放位置；
- 电子文件会按档案盒名称分文件夹存放。

> 提示：建议先维护好常用档案盒，再大批量登记档案，可显著提高效率。
