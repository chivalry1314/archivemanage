# 人员管理

人员管理用于维护员工/成员信息。人员在系统中主要用于：

- 任务指派；
- 档案保管人；
- 档案借阅人；
- 借还审批人。

## 人员列表

进入【人员管理】页面：

![人员列表](/images/members-list.png)

列表展示：

- 姓名
- 电话
- 邮箱
- 备注

## 添加人员

点击右上角 **+ 添加人员** 按钮，填写表单：

| 字段 | 说明 |
|------|------|
| 姓名 | 必填 |
| 电话 | 可选 |
| 邮箱 | 可选 |
| 备注 | 可选 |

点击 **添加** 保存。

## 搜索人员

在顶部搜索框输入姓名、电话、邮箱或备注中的关键字，系统会实时过滤列表。

## 编辑与删除

- **编辑**：点击 **编辑** 按钮，修改后保存；
- **删除**：点击 **删除** 按钮，确认后删除该人员。

> 注意：删除人员不会影响已关联的任务或档案记录，但这些记录中的人员名称可能会显示为缺失状态。建议在人员离职前先调整关联数据。

## 人员详情

双击人员行可查看详情弹窗，展示该人员的完整信息。
