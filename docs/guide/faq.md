# 常见问题

## 安装与启动

### 启动时提示缺少运行库？

Windows 用户若遇到启动失败，请确保系统已安装 [WebView2 Runtime](https://developer.microsoft.com/zh-cn/microsoft-edge/webview2/)。大多数 Windows 10/11 系统已自带。

### macOS 提示“无法打开应用”？

由于软件未经过 Apple 公证，首次打开时可能需要在 **系统设置 > 隐私与安全性** 中点击“仍要打开”。

## 数据相关

### 数据存储在哪里？

数据库文件路径可在【设置】页面查看。默认位于系统应用数据目录下。建议定期复制该 `.db` 文件进行备份。

### 如何备份数据？

最稳妥的方式：

1. 打开【设置】页面；
2. 复制显示的数据库文件路径；
3. 关闭软件（确保数据库不被占用）；
4. 复制 `.db` 文件到安全位置。

### 可以多人同时使用吗？

当前版本为单机桌面应用，数据库位于本地。如需多人协作，建议通过文件同步工具共享数据库文件，或使用手机搜索服务进行局域网查询。

## 任务提醒

### 为什么到时间了没有提醒？

请检查：

- 软件是否正在运行（关闭主窗口后应仍在系统托盘运行）；
- 操作系统是否禁用了该应用的通知权限；
- 任务是否正确设置了提醒时间。

### 逾期任务可以补录完成吗？

可以。在【仪表盘】或【任务管理】的实例列表中，点击逾期任务的 **完成** 按钮即可。

## 档案管理

### 档案编号是如何生成的？

档案编号由所选分类的“编号前缀” + 自动递增序号组成。例如分类前缀为 `YZ`，则第一条档案编号可能为 `YZ00001`。

### 为什么无法选择电子文件？

选择电子文件前必须先填写“档案盒名称”。填写后即可点击 **选择文件** 按钮。

### 借出后档案状态没有变化？

正常情况下，确认借出后档案状态会自动变为“借出”。如未变化，请检查是否保存成功，或尝试刷新页面。

## 其他

### 如何更新软件？

下载对应平台的最新安装包，直接覆盖安装即可。数据库文件会自动保留。

### 手机搜索服务打不开？

- 检查端口是否被其他程序占用；
- 检查 Windows 防火墙是否放行了该端口；
- 确保手机和电脑连接同一局域网。
