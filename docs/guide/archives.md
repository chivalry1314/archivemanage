# 档案管理

档案管理是系统的核心模块，用于登记、查询、借阅和归还物业档案。

## 档案统计

页面顶部显示 6 张统计卡片：

| 卡片 | 含义 |
|------|------|
| 总数 | 系统中登记的所有档案数量 |
| 在库 | 状态为“在库”的档案数量 |
| 借出 | 状态为“借出”的档案数量 |
| 损坏 | 状态为“损坏”的档案数量 |
| 销毁 | 状态为“销毁”的档案数量 |
| 逾期未还 | 借出已超期的档案数量 |

![档案统计](/images/archives-stats.png)

## 档案列表

点击 **档案列表** 标签，可查看所有档案：

![档案列表](/images/archives-list.png)

### 显示模式

- **普通**：按列表形式展示，支持搜索、分类筛选、状态筛选；
- **标签树**：左侧按标签层级展示，点击标签可筛选关联档案。

### 搜索与筛选

在普通模式下，可以：

- 按编号/名称/位置搜索；
- 按分类筛选；
- 按状态筛选（在库 / 借出 / 损坏 / 销毁）。

## 登记档案

点击右上角 **+ 登记档案** 按钮，填写档案表单：

![登记档案](/images/archive-form.png)

| 字段 | 说明 |
|------|------|
| 档案名称 | 必填 |
| 分类 | 必填，从【档案分类】中选择 |
| 存放位置 | 由所选档案盒自动带出，不可手动修改 |
| 数量 | 默认 1 |
| 档案盒 | 必填，从【档案盒维护】中选择 |
| 电子文件 | 可选，选择本地文件关联到该档案 |
| 保管人 | 可选，从【人员管理】中选择 |
| 备注 | 可选 |
| 标签 | 可选，从标签树中勾选 |

> 注意：选择电子文件前必须先选择档案盒。文件将保存到数据库同目录下，按档案盒名称分文件夹存放。

### AI 识别档案盒

如果在【设置】中开启了“档案盒 AI 识别”，登记档案时“档案盒”右侧会显示 **AI 识别** 按钮：

![AI 档案盒识别](/images/ai-archive-box.png)

1. 填写档案名称；
2. 点击 **AI 识别**；
3. 系统会调用配置的 AI 服务（如硅基流动），根据档案标题和分类推荐最合适的档案盒；
4. 如果推荐的是已有档案盒，点击 **采纳推荐** 即可；
5. 如果推荐的是新档案盒，可点击 **创建并采纳**，或调整名称后创建；
6. 也可点击 **选择其他** 手动挑选已有档案盒。

> 提示：AI 识别需要先在设置中配置 API 地址、模型名和 API Key。

## 编辑与删除档案

- **编辑**：点击 **编辑** 按钮，修改档案信息；
- **删除**：点击 **删除** 按钮，确认后删除该档案；
- **批量删除**：勾选多个档案后点击 **批量删除**。

## 借出档案

对于在库档案，点击 **借出** 按钮：

![借出档案](/images/borrow-form.png)

填写借还表单：

| 字段 | 说明 |
|------|------|
| 借阅人 | 必填，从人员中选择 |
| 借阅日期 | 必填，默认今天 |
| 应还日期 | 必填 |
| 借阅用途 | 可选 |
| 审批人 | 可选 |
| 备注 | 可选 |

点击 **确认借出** 后，档案状态会自动变为“借出”。

## 归还档案

切换到 **借还记录** 标签，找到需要归还的记录，点击 **归还** 按钮。系统会自动将归还日期设为当天，并将档案状态恢复为“在库”。

## 借还记录

借还记录标签展示所有档案的借阅历史：

![借还记录](/images/borrows-list.png)

- 顶部会显示当前处于借阅中的记录数量；
- 支持按状态筛选（借阅中 / 已归还 / 逾期）；
- 可编辑借还记录或删除单条记录。

## 档案详情

双击档案行可查看档案详情弹窗；双击借还记录行可查看借还详情弹窗。

## 打开电子文件

对于已关联电子文件的档案，点击 **打开文件** 按钮，系统会使用默认程序打开该文件。
