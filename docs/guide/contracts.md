# 合同管理

合同管理用于登记和维护各类合同台账（如保洁、维保、租赁合同），支持 Excel 批量导入和台账导出，方便快速建立合同档案。

## 进入合同管理

点击左侧菜单 **合同管理**，进入合同列表页面。

![合同列表](/images/contracts-list.png)

## 合同字段

| 字段 | 说明 |
|------|------|
| 合同名称 | 必填 |
| 合同编号 | 可选，如“HT-2026-001” |
| 合同甲方 / 合同乙方 | 可选，合同双方当事人 |
| 对方联系人 / 联系方式 | 可选 |
| 合同总金额（含税/不含税）、税额 | 可选，单位为元 |
| 付款周期 | 可选，如“月度”、“季度” |
| 每次支付金额（含税） | 可选，单位为元 |
| 付款方式 | 可选，如“银行转账” |
| 生效日期 / 终止日期 / 签订日期 | 可选 |
| 甲方经办人 / 乙方经办人 | 可选 |
| 备注 | 可选 |

## 增删改查

- **添加**：点击右上角 **+ 添加合同**，在弹出的表单中填写信息后保存。只有“合同名称”为必填项；
- **编辑**：点击行尾的 **编辑** 按钮；
- **删除**：点击行尾的 **删除** 按钮，确认后删除；
- **批量删除**：勾选列表前的复选框，点击顶部出现的 **批量删除** 按钮；
- **查看详情**：双击合同编号或合同名称，弹出完整的合同详情；
- **搜索**：顶部搜索框支持按合同编号、名称、甲方、乙方、经办人模糊搜索；
- **分页**：底部可切换页码，每页条数在【设置】中统一调整。

## Excel 导入

1. 点击 **下载模板**，保存“合同导入模板.xlsx”，模板中带有两级表头和一行示例数据；
2. 按模板格式填写合同数据（可删除示例行）；
3. 点击 **导入**，选择填好的 Excel 文件；
4. 导入完成后页面会提示新增的记录条数。

> 提示：金额列直接填写以“元”为单位的数字；日期列使用 `YYYY-MM-DD` 格式。

## 台账导出

1. 在右上角选择导出格式（Excel 或 CSV）；
2. 点击 **导出**：
   - Excel 会弹出保存对话框，默认文件名为 `合同台账_日期.xlsx`；
   - CSV 会直接下载，默认文件名为 `合同台账_日期.csv`。
