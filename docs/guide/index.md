# 文档概述

欢迎使用 **档案管理OS** 操作文档。

本软件是一款面向物业/企业场景的桌面应用，集 **任务提醒** 与 **档案管理** 于一体，帮助团队：

- 跟踪周期性任务（月度、季度、半年度、年度）的执行情况；
- 管理人员信息，作为任务指派与档案借阅的关联对象；
- 建立物业档案台账，记录分类、标签、存放位置、保管人、电子文件；
- 管理档案借还流程，自动提醒逾期归还；
- 通过局域网手机搜索服务，在手机上快速检索档案。

## 适用对象

本文档面向：

- 初次使用该软件的物业管理人员；
- 需要了解各功能模块操作步骤的一线员工；
- 负责系统维护、数据备份与导出的管理员。

## 界面总览

软件主界面采用经典的侧边栏布局：

- **左侧边栏**：导航菜单，包含仪表盘、任务管理、人员管理、档案管理、档案盒维护、档案标签、档案分类、设置；
- **顶部标题栏**：显示当前页面名称；
- **右侧内容区**：展示当前页面的功能与数据。

![主界面](/images/main-layout.png)

> 提示：关闭主窗口后，软件会驻留在系统托盘继续运行提醒服务。需要彻底退出时，请在系统托盘图标上右键选择退出。
