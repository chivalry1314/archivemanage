# 仪表盘

仪表盘是登录后的默认首页，集中展示任务相关的核心数据与待处理事项。

![仪表盘](/images/dashboard.png)

## 统计卡片

页面顶部有 4 张统计卡片：

| 卡片 | 含义 |
|------|------|
| **今日待办** | 截止日为今天且未完成的任务实例数量 |
| **待办任务** | 当前所有未完成的任务实例总数 |
| **逾期任务** | 已超过截止日期且未完成的任务实例数量 |
| **已完成** | 已标记为完成的任务实例数量 |

点击卡片不会跳转页面，仅用于快速了解整体情况。

## 今日待办

列出截止日为今天的任务实例，每条显示：

- 任务名称
- 负责人
- 任务周期
- 截止日期

### 标记完成

点击任务右侧的 **完成** 按钮，可将该实例标记为已完成。完成后按钮变为 **撤销完成**，点击可恢复为待办状态。

## 逾期任务

列出已超过截止日期的任务实例，状态标签显示为红色。对于已逾期的任务，同样可以点击 **完成** 按钮进行补录。

## 分页

今日待办和逾期任务列表均支持分页，可在列表底部切换页码。每页显示条数可在【设置】中调整。
