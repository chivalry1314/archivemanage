# 档案管理OS - 任务提醒 + 物业档案管理工具

一个基于 Tauri + Vue + Rust 的桌面工具，包含两大模块：

- **任务提醒**：按月/季度/半年/年设置周期性任务，可指派多人，到期自动桌面提醒。
- **档案管理**：适合真实物业场景的纸质档案登记、分类管理、借出归还、逾期提醒、台账导出。

## 功能

### 任务提醒

- **任务管理**：创建周期性任务，周期可选每月/每季度/每半年/每年。
- **人员管理**：添加员工信息，任务可指派给零个或多个员工。
- **桌面提醒**：任务到期前自动弹出系统通知，可播放提示音。
- **完成确认**：经理在软件中点击"完成"打勾确认每个周期的任务。

### 档案管理

- **档案分类**：自定义分类及编号前缀，如业主档案（YZ）、设备档案（SB）、合同档案（HT）。
- **档案登记**：录入纸质档案，档案编号按分类自动生成为 `前缀-年份-序号` 格式。
- **借出归还**：借阅人只能从现有员工中选择，记录借阅日期、应还日期、审批人。
- **逾期提醒**：档案到期前/超期未还时自动桌面提醒。
- **状态管理**：在库、借出、损坏、销毁。
- **借阅历史**：每份档案可查看完整借还记录。

### 数据导出与备份

- 导出任务实例 CSV、人员统计 CSV、完整数据 JSON。
- 导出档案台账 CSV、档案借还记录 CSV。
- SQLite 数据库文件可手动备份与恢复。

### 系统托盘

关闭主窗口后，软件在托盘常驻，继续执行提醒。

## 运行方式

### 方式一：直接运行（推荐）

打开 `release/档案管理OS.exe` 即可运行。

数据文件存放在：

```
%APPDATA%\com.dshj5.archive-management-os\task_reminder.db
```

### 方式二：开发调试

```bash
npm install
npm run tauri dev
```

### 方式三：打包安装包

```bash
npm run tauri build
```

> 打包 Windows MSI 需要下载 WiX 工具集，首次打包可能因网络下载较慢。如果仅需要可执行文件，可以直接使用 `release/档案管理OS.exe`。

## 使用流程

### 任务提醒

1. 进入"人员管理"，添加员工名单。
2. 进入"任务管理"，新建任务：
   - 选择周期（每月/季度/半年/年）
   - 设置每月几号触发
   - 选择被指派的员工（可选）
   - 设置提前提醒分钟数、是否播放声音
3. 到达设定时间后，桌面会自动弹出通知提醒。
4. 经理在"仪表盘"或"任务管理"中查看任务，员工完成后点击"完成"打勾。

### 档案管理

1. 进入"档案分类"，维护分类及编号前缀。
2. 进入"档案管理"，点击"登记档案"：
   - 选择分类（编号自动生成）
   - 填写档案名称、存放位置、保管人
3. 在库档案可点击"借出"，选择员工借阅人、应还日期。
4. 借出到期前会自动提醒，超期后会标记为逾期。
5. 档案归还后点击"归还"，系统自动把档案状态改回"在库"。
6. 在"设置"页可导出档案台账和借还记录 CSV。

## 档案编号规则

档案编号根据分类自动编号，格式为：

```text
{分类前缀}-{年份}-{3位序号}
```

例如：

- 业主档案：`YZ-2026-001`
- 设备档案：`SB-2026-015`
- 合同档案：`HT-2026-003`
